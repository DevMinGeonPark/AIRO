## 1. 판정: 조건부 승인 (방향·구도는 통과, 아래 1~4번 해결 전까지 최종 승인 보류)

"종이 지도 위의 대화"는 실제 렌더에서 성립합니다. hero-day1은 지도가 뷰포트 전체를 채우고, 가모가와·교토교엔·히가시야마 워시·한글 지명 5개 이상이 읽히며, 왼쪽 카피 → 가운데 카드 → 오른쪽 경로의 시선 흐름이 한 장면으로 묶입니다. 좌표는 Day1 135.798° → Day3 135.673°로 실제로 이동하고, 오버뷰는 세 날을 한 프레임에 담고 요약 알약과 CTA로 닫힙니다. 이전 리뷰의 "회색 박스·광택 핀·10px UI" 문제는 모두 사라졌습니다.

그러나 모든 지도 인스턴스에 공통된 핀 위치 결함이 있어, 그대로는 승인할 수 없습니다.

## 2. 우선순위 수정 (최대 6개)

**1. [차단] 핀이 좌표 위에 있지 않음 — 모든 지도 공통**
- 증거: hero-day1 핀 1 꼭짓점 (1113, 625) vs 경로 시작점 (1128, 683) = 58px 위. 핀 3 (1240, 215) vs 경로 끝 (1252, 270) = 55px. hero-day2 핀 1 (763, 330) vs (778, 388). feature-2 핀 1 (530, 760) vs (541, 815). feature-1 미니맵, cta, hero-375도 동일. 반면 hero-overview(scale .177)에서는 오차 0~5px.
- 진단: 오프셋이 카메라 스케일에 비례해 커지므로 핀 본체가 화면 단위가 아니라 월드 단위로 위로 밀려 있습니다. 좌표 지점에는 그림자 타원과 경로 점만 남고 번호 핀은 허공에 떠 있어, "핀이 떨어진다"는 핵심 인과가 깨집니다.
- 요구: `.geo-pin-body` 꼭짓점이 `translate(screenX, screenY)` 원점에 정확히 오도록, 본체 오프셋은 화면 px로만 적용. 승인 기준: scale .44 / .64 / .177 모두에서 꼭짓점과 경로 정점 거리 ≤ 4px, 그림자 타원이 꼭짓점 바로 아래.

**2. [차단] 나침반 "N"이 페이지 전체에 고정 노출**
- 증거: mcp.png (38, 862), feature-2-375 (18, 770), mcp-375 (18, 730)에 히어로의 N 버튼이 그대로 보임. hero-768에서는 리드아웃 두 번째 줄 "은각사"(55, 975)와 겹치고, hero-375-card에서는 카드의 아이로 아바타(48, 660) 근처와 어트리뷰션(30, 795)과 충돌.
- 요구: 지도는 항상 north-up이고 리드아웃이 이미 좌표를 보여주므로 나침반은 제거. 남기려면 `.hero-section` 내부 `position: absolute`로 두고 리드아웃 한 줄에 "N ↑ 35.02691° N …" 형태로 합침. 승인 기준: 히어로 밖 어떤 스크린샷에도 N 버튼이 없음.

**3. [차단] 375 첫 화면 구성 — 칩이 핀을 가리고 카드가 잘림**
- 증거: hero-375-day1 핀 3 (185, 510)이 "Day 3" 칩 아래에 절반 묻힘. hero-375-day3 핀 3 (123, 510)이 "Day 1" 칩에 가려짐. 카드는 y 730부터 시작해 첫 화면에 AI 답변 한 줄만 보임. hero-375-card(scroll 98)에서 아이브로우 "나의 AI 여행 파트너, 아이로"가 로고 위에 그려짐 = 히어로 카피가 네비보다 z-order가 높거나 nav-glass가 미작동.
- 910px 타협에 대한 판단: CTA·경로·답변 첫 줄이 폴드 안에 있어 원칙적으로는 허용 가능하지만, 아래 조정으로 812 안에 카드까지 넣을 수 있으므로 타협을 유지할 이유가 없습니다.
- 요구 (총 약 -116px):
  - `.hero-note` ≤767에서 `display: none` (-40px), 카피 상단 오프셋 120 → 100px (-20px).
  - 모바일 카드는 헤더("느긋하게, 교토 / 화면 미리보기")와 사용자 문장을 제거하고 아이로 답변 + "09:00 · 대나무 숲 / 일정에 담김" 두 줄만 (약 -56px, 높이 ≈ 96px).
  - Day 칩은 높이 34px, 우측 정렬 폭 200px, "지도 조작"은 아이콘 전용 36px 원형. 모바일 fit에 상단 패딩 64px을 주어 경로 북쪽 끝이 칩 아래로 내려오게.
  - `.landing-nav` z-index > `.hero-copy`, scroll > 20에서 glass 불투명 확인.
  - 승인 기준: 375×812 scroll 0에서 핀 3개·지명·카드 2줄·CTA가 겹침 없이 모두 보임, 본문 ≥ 14px 유지.

**4. [차단] reduced-motion 히어로가 오버뷰 스케일이라 카피와 카드가 핀을 덮음**
- 증거: hero-reduced에서 h1 "어디로든,"(x 80~360, y 270~420) 뒤로 "아라시야마" 라벨과 Day 3 핀 클러스터(x 163~206)가 비쳐 보임. 카드(833~1193 × 300~560)가 Day 2 클러스터(975~1065 × 530~590)를 덮고 핀 하나만 아래로 삐져나옴.
- 요구: 제 1차 스펙("reduced = 오버뷰")을 철회합니다. reduced/off는 hero-day1과 동일한 Day 1 fit(scale .44, 경로 우측, 카드 중앙)으로 고정하고 Day 칩 클릭 시 즉시 점프. 승인 기준: hero-reduced가 hero-day1과 같은 구도이고 핀 9개 중 화면 안 핀이 카피·카드에 가려지지 않음.

**5. [내 코드] 기능 03 오른쪽 엽서 라벨 은닉 + 배경 워시 과다**
- 증거: feature-3와 feature-3-375 모두 오른쪽 카드에 북마크 아이콘(540, 447)만 보이고 "예산 / 여행 예산"이 가운데 카드에 가려짐. 왼쪽 카드도 "가고 싶은 곳에 담기"가 x 228에서 잘림. feature-prep 워시는 50%에서 마스크 경계(60~660 × 60~630)가 사각형으로 드러나 탁함.
- 수정(scroll-scenes.tsx / landing.css): 펼침 x를 `45%` → 데스크톱 `60%`, 모바일 `46%`, 회전 ±7 → ±6. `.postcard:last-child .postcard-meta { justify-items: end; text-align: right }`로 오른쪽 카드 라벨을 바깥쪽에. `.postcard-desk { opacity: .32; mask-image: radial-gradient(52% 52% at 50% 48%, #000 0%, transparent 100%) }`. 승인 기준: 세 라벨(맛집·예약·예산)이 1440과 375 모두에서 온전히 읽힘.

**6. [내 코드 + 루트] 소형 충돌 묶음**
- feature-2-375: "© OpenStreetMap"(245~327, 628)이 좌표 줄(150~327, 612)을 덮고, "KYOTO, JAPAN · DAY 1"이 "난젠지" 라벨(137~167, 572)과 근접. 1440에서도 "©"가 컨테이너 우측 끝(1233)에 걸림. 수정: `.feature-map .map-attribution { left: 16px; right: auto; bottom: 12px }`, `.band-readout` 375에서 `bottom: 56px`.
- mcp-reduced: `.beam-dot`가 선 시작점(460, 235)에 상시 노출. 수정: 기본 `opacity: 0`, 타임라인에서만 1.
- mcp-reduced 전체가 약 35% 불투명도로 캡처됨 = `.mcp-card` Reveal 페이드가 진행 중이거나 멈춤. 루트 확인 필요: reduced에서 1초 후 100%인지.
- cta 엽서 캡션 "계획은 가볍게. 여행은 나답게."가 모노 폴백으로 자간이 벌어짐. 수정: `.cta-postcard figcaption { font: 13px var(--font-geist-sans) }`.
- feature-1 캡처에 둘째 결과 칩("골목 안 작은 카페 · 15:00")이 없음. ScrollTrigger 88% 미도달 캡처일 가능성이 크지만 확인 필요.

## 3. 실질적으로 나아진 점

- 지도가 장소로 읽힙니다. 강·궁원·산지·역이 식별되고 지명 위계(한글 + 로마자 소문자)가 일관됩니다.
- 히어로 UI 클러스터가 8개 → 6개(나침반 제거 시 5개)로 줄었고, 가장 작은 텍스트가 12px입니다.
- Day 2·3 프레임에서 카드가 경로 왼쪽에 앵커돼 중간 핀을 덮지 않습니다. 카메라 이동 거리도 화면에서 체감됩니다.
- 하단 섹션은 회색 프레임 없이 종이 위에 놓였고, MCP는 두 창 + 허브 구도가 1440·375 모두에서 그대로 성립합니다.
- CTA는 헤드라인 좌·지도 우·엽서 우하로 무게가 분산돼 마무리 장면으로 읽힙니다.
