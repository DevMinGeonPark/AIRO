# AIRO 로고 색상 추천 · 2026-09-09

추천은 검정 `#0A0A0A` 위의 에어 블루 `#86A5FF`다. 제비와 AIRO 전체를 같은 색으로 표시하고, 핵심 버튼·선택 상태에 같은 색을 반복한다. 본문은 기존 밝은 중립색을 사용한다. 비교 화면은 승인된 원본 WebP를 CSS 마스크로 표시한다.

## 현재 화면의 진단

현재 가로형 로고는 밝은 회색, 단독 제비와 버튼은 아이보리다. 아이보리와 검정의 대비는 약 14.09:1로 충분하다. 가독성보다 로고가 일반 글자와 구분되는 정도를 개선할 여지가 있다. 이 평가는 현재 화면을 보고 내린 디자인 판단이다.

## 조사한 원칙

1. [Google Material 색상 가이드](https://codelabs.developers.google.com/customizing-material-color): 중립색은 바탕과 내용, 주요 색은 강조할 조작부에 배정한다. 더 강한 보조색이 주요 색보다 주목받지 않도록 위계를 정한다. 이 원칙을 AIRO의 단일 브랜드 색에 적용한다.
2. [W3C WCAG 2.2 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): 일반 글자 4.5:1, 큰 글자 3:1. 로고 예외가 있지만 홈 링크로 쓰이는 작은 로고도 읽기 쉽도록 설계한다.
3. [W3C 비텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): 조작부나 상태를 식별하는 데 필요한 시각적 정보는 인접색과 3:1을 기준으로 검사한다. 장식용 모든 경계선이 일률적으로 3:1이어야 한다는 의미는 아니다.
4. [Google Labs DESIGN.md](https://github.com/google-labs-code/design.md): 정확한 디자인 값과 적용 이유를 함께 기록하는 문서 형식이다. 특정 색의 우수성을 증명하는 색상 이론은 아니다. 현재 alpha 형식을 참고해 이 폴더의 DESIGN.md에 추천안과 역할을 기록했다.

## 후보 비교

아래 인상은 조사 원칙을 현재 AIRO에 적용한 주관적 판단이다. 색이 감정·전환율을 보장한다는 주장으로 해석하지 않는다.

| 후보 | 검정 배경 대비 | 카드 배경 대비 | 판단 |
| --- | ---: | ---: | --- |
| 에어 블루 `#86A5FF` | 8.33:1 | 7.55:1 | 1순위. 제비의 비행 이미지, 차가운 지도 바탕과 잘 연결되고 본문색과 쉽게 구별된다. |
| 라벤더 `#A69AFF` | 8.19:1 | 7.42:1 | 2순위. 개성이 있지만 여행보다 AI 도구의 인상이 앞선다. |
| 기존 아이보리 `#E7D8BC` | 14.09:1 | 12.76:1 | 따뜻하고 읽기 편하지만 밝은 회색 로고/본문과 브랜드 위계가 약하다. |

밝은 브랜드색에는 검정 버튼 글자를 쓴다. 블루 위 흰 글자 대비는 2.38:1이다. 흰 버튼 글자를 유지하려면 버튼 바탕을 더 어두운 블루로 별도 설계해야 한다. 추천안은 검정 배경에서 로고와 주요 버튼의 색을 통일한다.

계산은 WCAG의 sRGB 상대 명도 공식을 사용한다. `c <= 0.04045`이면 `c / 12.92`, 그 외에는 `((c + 0.055) / 1.055)^2.4`; 상대 명도는 `0.2126 R + 0.7152 G + 0.0722 B`; 대비는 `(밝은 명도 + 0.05) / (어두운 명도 + 0.05)`다. 표의 수치는 소수 둘째 자리로 표시했으며 실제 투명도·지도 위 배치·렌더링과 인터랙션은 채택 후 별도 검증 대상이다.
