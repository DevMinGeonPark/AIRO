## Supabase 실제 연결 — 2026-09-08

- MCP OAuth 인증 완료. 이 세션의 도구 목록은 자동 갱신되지 않아 `.private/supabase-mcp.mjs`가 정상 OAuth 저장소를 사용해 공식 MCP 서버를 호출한다. 토큰 값은 출력하거나 저장 파일에 복제하지 않는다.
- AIRO 조직에 있던 빈 프로젝트를 사용하고 표시명을 `airo`로 변경했다. 새 유료 프로젝트는 생성하지 않았다.
- `0001`~`0004` 마이그레이션 적용 완료. public 테이블 10개 모두 RLS가 활성화돼 있다.
- 가입 프로필 생성 트리거의 직접 RPC 실행 권한을 제거했다. `api_key_owner`의 SECURITY DEFINER 실행 권한은 외부 MCP 토큰 인증을 위해 의도적으로 유지한다.
- 실제 DB의 트랜잭션 안에서 가입 트리거, 본인 조회, 다른 계정의 조회·쓰기 차단을 검증한 뒤 전체 롤백했다. 테스트 사용자가 남지 않았음을 확인했다.
- `.env.production.local`에 URL과 Publishable key를 넣고 기존 OpenAI 설정을 보존했다. 설정 변경 전 파일은 `.private/supabase-before`에 보관한다.
- `.next-supabase` production build 및 lint 통과. 별도 서버에서 익명 API 401, 로그인 화면 이동, 이메일 로그인 UI를 검증했다.
- 대상 이메일의 실제 앱 계정은 아직 생성되지 않았다. 개인 원본과 내보내기 파일은 유지했으며 실제 이식과 3401/3402 운영 전환은 미실행이다.

## AIRO 도메인 배포 — 2026-09-08

운영 주소: **https://airo.dev-heptivision.com**. DNS, HTTPS, 로고/화면, 로그인 이동, MCP 문서의 새 주소를 실제 외부 접속으로 확인했다. `.env.production`의 공개 주소와 로그인·로그아웃 리다이렉트를 새 주소로 맞췄다. 프록시 뒤에서 내부 localhost로 돌아가던 인증 리다이렉트도 수정했다.

새 운영 프로세스는 127.0.0.1:3410, 빌드는 `.next-airo-live`이며 macOS LaunchAgent가 관리한다. 전용 AIRO Cloudflare 터널을 연결해 기존 터널과 3401/3402 프로세스는 변경하지 않았다. 운영 설정은 `DEPLOYMENT.md`, 기기별 설정 사본은 `.private/deployment/`에 있다.

Supabase 대시보드에서 확인할 값:
- Site URL: `https://airo.dev-heptivision.com`
- Redirect URLs: `https://airo.dev-heptivision.com/auth/callback`, `http://localhost:3002/auth/callback`

사용자가 위 Auth URL 설정 저장을 확인했다. 대상 계정의 실제 로그인은 아직 확인되지 않았다. 보존된 세 여행 파일의 형식과 PDF 해시를 검사했으며 이식 전 검증 기록은 `.private/migration-preflight.json`에 있다. 원본 여행과 기존 주소는 이식 검증이 끝날 때까지 보존한다.

## AIRO 브랜드 식별자 정리 — 2026-09-08

화면·문서·MCP·새 API 키(`airo_`)·여행 파일(`airo-trip`)·즐겨찾기 파일(`airo-saved`)을 AIRO로 통일했다. 옛 개발 호스트와 서버 메모리 이름을 정리했다. 개인용 저장 키는 `airo.saved.v1`으로 이전하며 저장 실패 시 원본을 유지한다. 이전 여행 파일과 즐겨찾기는 가져오기에서만 변환한다. 사전 백업은 `.private/brand-cleanup-before/`에 있으며, 현재 이식 파일은 형식 필드만 변경하고 모든 자료를 보존했다. 기존 데이터 경로와 과거 마이그레이션은 운영·복구 기록이다.

`0005_airo_archive_format.sql`을 실제 Supabase에 적용했다. 기존 프로필 1개·여행 0개와 RLS 10개를 확인했다. 자료 파일/PDF 해시, 로컬 PostgreSQL 트랜잭션·계정 격리, 로그인 후 9개 화면, 내보내기, AIRO 키 발급·MCP 인증을 검증했다. `.next-airo-clean` 빌드를 공개 3410과 Tailscale 3016에 반영했다. 검증 기록은 `assets/validation/brand-cleanup/`에 있다.
