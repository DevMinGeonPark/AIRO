### 앱 소개 경험

사용자: 웹 랜딩이 잘 나왔으니 앱에서도 서비스가 무엇인지 설명하는 경험을 기존 리소스로 만들 수 있는지 논의하고 싶다고 함.

제안 후보: ‘사진으로 여행에 들어가서, 짧은 예시를 직접 눌러보고, 내 여행으로 이어지는 시작 화면’.

1. 제비 로고·로마 골목 사진·기존 브랜드 문구로 첫 장면 구성.
2. 로마/교토 등 소수 도시 사진을 넘겨 선택. 도시 소개·사진은 기존 웹 자료 재사용.
3. ‘카페에 들르고 싶어’ 같은 예시 선택 → 기존 경로와 장소 핀/일정 카드가 나타나는 짧은 체험. 실제 AI 요청처럼 속이지 않고 ‘예시 여행’임을 표시하며 미리 준비한 데이터로 동작.
4. ‘내 여행 시작하기’에서 로그인으로 연결. 고른 도시/예시를 내 여행으로 만들지는 별도 선택이며 자동으로 계정에 쓰지 않는다.
5. 로그인 사용자는 내 여행으로 직행. 소개 다시 보기는 사용자가 원할 때 접근.
