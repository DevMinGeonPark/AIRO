# Day별 숙소 정보 모달

2026-09-19. 웹 운영 release `day-accommodation-20260919`와 Android 0.3.8/code 11에 반영했다.

Day 일정 헤더의 `숙소` 또는 `숙소 정보` 버튼을 누르면 해당 날짜의 숙소 일정만 별도 모달로 열린다. 숙소 이름·체크인 시간·메모, 연결된 예약 기록과 예약 deeplink, 지도 열기 링크를 한 곳에서 확인한다. 숙소가 여러 개면 모두 표시하고, 등록된 숙소가 없으면 안내 문구를 보여준다. 모달 바깥이나 닫기 버튼으로 일정 화면에 돌아온다.

숙소 판별은 stop의 `stay` 모드와 이름·검색어·메모의 숙소/호텔/Hotel/hostel/Airbnb/inn 표기를 함께 사용한다. 기존 일정 데이터나 예약 자료를 바꾸지 않으며, 지도 현재 위치 버튼은 숙소 버튼과 겹치지 않도록 지도 아래쪽으로 이동했다.

웹과 Android 모두 별도 숙소 편집 API를 호출하지 않는다. 기존 여행 조회 결과와 연결된 첨부·예약 자료를 읽어 표시한다. 지도 링크는 기존 안전한 지도 URL 생성기를 사용한다.

검증은 웹 lint 및 production build, Android Cloud/Demo 단위 테스트·Lint, 기존 선택형 일정·현재 위치 회귀를 통과한 뒤 운영으로 교체했다. 공개 `/login`·모바일 인증 설정·MCP 문서는 200, 비인증 모바일/API는 401이며 MCP 29개 도구를 유지한다. Android Cloud/Demo 0.3.8 APK 전체 다운로드와 SHA-256도 확인했다.

앱 업데이트는 **내 정보 → 설정 → 앱 업데이트**에서 진행한다.
