# Day 0 준비 목록·장소 복사·국내 지도

- 일정에 장소가 없어도 Day 0(출국 전날)·Day 1을 선택할 수 있다. 두 날의 Todo는 같은 준비 목록을 연다. 날짜는 여행 시작일 하루 전이며, 시작일 미정이면 오늘을 Day 1로 계산한다.
- 일정 패널과 모바일 지도 오버레이의 `출국 전날 Todo`에서 준비 목록을 연다. 챙길 것·여권/비자/서류·출국 준비를 체크하거나 항목을 추가/삭제한 뒤 `저장하고 닫기`를 누른다.
- 일본국대사관 비자 안내와 Visit Japan Web 입국·세관 등록은 별도 공식 링크다. 비자 신청이나 알림 발송을 자동 실행하지 않는다.
- `trip_archives.data.predepartureChecklist`에 여행별로 저장한다. 최대 100개, 이름 200자. `/api/trips/[tripId]/predeparture` GET/PUT은 계정 인증과 소유권을 확인한다. RPC는 revision 충돌을 거절하고 기존 자료를 보존한다. 서버 오류·충돌 시 작성 목록을 유지하며 최신 목록 교체에는 사용자 확인이 필요하다.
- `0012_predeparture_checklist.sql`은 저장 RPC와 기존 감사/되돌리기 함수에 체크리스트를 연결한다. 되돌려도 revision은 증가한다. 내보내기/가져오기에 포함되며 새로운 MCP 도구는 추가하지 않는다.
- 장소 상세와 자료·맛집의 이름 옆 `복사` 버튼을 누르면 클립보드에 이름을 저장한다. 권한 거절 시 실패를 알리고 선택 가능한 텍스트를 안내한다.
- 한국 좌표는 네이버지도 검색·카카오맵 좌표 보기·카카오 길찾기로 연결한다. 해외는 구글지도다. Natural Earth의 공개 영역 경계 데이터를 로컬에서 판별하며 별도 지도 API를 호출하지 않는다. 제주·울릉·독도·백령도 및 인천공항을 검증했고, 대마도·후쿠오카·개성은 국내로 분류하지 않는다. 이 경계는 지도 서비스 선택용이다.

검증: Chrome 1440/390·WebKit 320의 모달·저장/재열기·추가/삭제·오류 재시도·충돌·복사 및 거절·지도 링크, 로컬 PostgreSQL의 소유권·읽기 전용 권한·revision·이력 복원·기존 PDF 보존, TypeScript·ESLint·운영 빌드. 증거는 `.private/deployment/domestic-maps-predeparture-20260918/`와 `assets/validation/workspace/`에 보관한다.
