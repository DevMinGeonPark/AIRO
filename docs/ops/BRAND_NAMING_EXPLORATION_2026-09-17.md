# AIRO 이름 대안 조사 — 영어권 우선

기록: 2026-09-17 16:47 KST. 상태: 아이디어 비교, 이름 변경 미승인.

## 최신 사용자 피드백 — 친근하게 부를 수 있는 이름

사용자: ‘아이로처럼 친근하면서 부르기 편한’ 느낌을 원한다. 앞선 여행 의미 중심 후보의 순위는 확정하지 않는다. 영어권 고려 조건도 계속 유지한다.

새 방향: 한국어로 받침 없는 2~3음절, 사람·여행 친구에게 말 걸듯 부를 수 있는 이름. 여행을 뜻하는 영어 단어를 반드시 넣지 않는다. 귀여움/편안함과 영문 철자의 발음 예측 가능성을 함께 검토한다.

현재 어감 선호는 Luiro, 차분한 방향은 Nuaro. 이는 어감 비교일 뿐 등록 가능성이나 원어민 테스트를 통과했다는 뜻이 아니다. 도메인/상표 미확인, 이름 변경 미승인.

추가로 살펴본 Rilo, Luvo, Moru, Ronu, Melu, Nelu, Rolu, Luaro, Liroa, Nairo는 이미 앱·소프트웨어·유관 서비스에 쓰이고 있어 우선 추천에서 제외했다. 특히 [Luvo는 여행 계획 앱](https://luvo.elvarsystems.co.uk/), [Rilo는 위치 기반 기록 앱](https://www.rilo.life/)이다. Moiro는 화장품 브랜드 사용, Nuiro는 기존 사이트 사용이 검색되어 우선순위를 낮췄다.

## 사용자 요구

- 기존 AIRO와 다른 회사의 이름 중복을 우려하며, 입에 붙는 이름을 원한다.
- 영어권을 고려해야 한다. 영어로 자연스럽게 부르고 한국어에서도 기억하기 쉬운 이름을 우선한다.
- 기존 새 심볼·블루·다크 UI·여행 사진은 새 이름에서도 활용할 수 있다.
- 이번 작업은 공개 웹 검색과 메모 작성이다. 앱·웹 이름, 패키지 ID, 도메인, 인증 설정, 로고를 변경하지 않았다. 도메인 구매·별도 과금 API 호출·이미지 생성은 하지 않았다.

## 조사 범위와 한계

정확한 영문 이름 검색, 이름과 travel/app/software 조합 검색, 확인 가능한 공식 서비스·앱스토어·기업등록 페이지를 비교했다. Ramblet, Rambleaf, Roamfin, Outlark, Fledra는 앱스토어/Google Play 도메인으로 제한한 웹 검색도 수행했다. 이는 스토어 내부의 모든 국가·등록명을 조사한 것이 아니다.

검색에서 직접 중복을 찾지 못한 것과 사용 가능 판정은 다르다. 상표 등록·출원 및 유사 발음의 권리 검토, 대부분의 도메인 등록 가능 여부, 원어민 발음/철자 회상 테스트는 아직 하지 않았다. 아래 읽기는 브랜드로 의도한 발음이며 실제 사용자 테스트 결과가 아니다. 영어 느낌·장단점은 디자인 판단이다.
