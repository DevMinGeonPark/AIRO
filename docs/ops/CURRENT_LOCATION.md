# 지도 현재 위치 — 0.3.8 / code 11

2026-09-19. 웹과 Kotlin/Compose Android 지도 오른쪽 위에 **현재 위치** 버튼을 추가한다. 지도 조작부를 숨겨도 버튼은 보인다. 누르면 위치 권한을 확인하고 파란 점을 표시하며 해당 좌표로 지도를 이동한다. 재생 중에는 경로 재생을 멈추고 장소 상세 카드를 닫는다. 반복해서 누르면 현재 위치로 다시 중심을 맞춘다.

- 사용자가 눌렀을 때만 위치를 요청한다. 자동 완료용 위치 추적은 켜지지 않으며 이 버튼의 좌표는 서버에 전송하거나 저장하지 않는다.
- 최근 30초 이내 위치만 재사용하고 새 위치 요청은 15초 후 시간 초과 안내를 표시한다. 정확도에 따라 지도의 확대 수준을 조정한다.
- 권한 거부·기기 위치 꺼짐·시간 초과를 안내하고 재시도할 수 있다. Android에서는 위치/앱 설정으로 이동할 수 있다.
- 화면을 떠나면 Android 위치 리스너를 해제하고 브라우저의 늦은 응답을 무시한다. 복귀 후 버튼을 다시 누르면 된다.

## 구현

웹 `current-location-control.tsx`는 브라우저 Geolocation과 기존 MapMarker를 사용한다. Android `CurrentLocation.kt`는 기존 위치 권한과 플랫폼 LocationManager를 사용하고, NativeMap에 별도 현재 위치 점/외곽 원 레이어를 둔다. 외부 위치 서비스·별도 API 키·과금 API·새 백그라운드 권한은 추가하지 않는다.
